## Download and install

Download **PUSE-PSP-v0.5.1.zip** from the Assets section below.

1. Extract the complete `PUSE-PSP` folder.
2. Copy it to `ms0:/PSP/GAME/PUSE-PSP/` on the PSP Memory Stick.
3. Confirm that `EBOOT.PBP` and the `data` folder are both inside that folder.
4. Exit Pokemon Unbound and your GBA emulator completely.
5. Start **PUSE-PSP** from the PSP Game menu.

Keep a separate manual backup while this release is experimental. PUSE-PSP
also creates a `.puse.bak` file before replacing a save.

## v0.5.1 highlights

- Increased the UI from an unreadable 8x9 grid to 12x16 pixel cells
- Rendered 14 px Source Code Pro glyphs at native size instead of shrinking them
- Fixed alternating invisible menu rows by retaining and redrawing full frames
- Added a wrapped full-path panel to the save picker
- Added Hoopa artwork to the PSP icon and XMB background
- Preserved every save-editing feature from v0.5.0

The editor remains completely offline and optimized for the PSP's 480x272 LCD.
