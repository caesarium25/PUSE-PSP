## Download and install

Download **PUSE-PSP-v0.5.0.zip** from the Assets section below.

1. Extract the complete `PUSE-PSP` folder.
2. Copy it to `ms0:/PSP/GAME/PUSE-PSP/` on the PSP Memory Stick.
3. Confirm that `EBOOT.PBP` and the `data` folder are both inside that folder.
4. Exit Pokemon Unbound and your GBA emulator completely.
5. Start **PUSE-PSP** from the PSP Game menu.

Keep a separate manual backup while this release is experimental. PUSE-PSP
also creates a `.puse.bak` file before replacing a save.

## v0.5 highlights

- Replaced the PSP debug-text display backend with native SDL2 rendering
- Bundled Source Code Pro Regular and Semibold under the SIL Open Font License
- Hardware-drawn header, surface, selection, hint, and calculated-stat panels
- Graphical green O and red X controller badges in commands
- Proper font weight and color hierarchy for headings, warnings, and status
- Preserved every v0.4 editing feature and the clock-free branded XMB artwork

The editor remains optimized for the PSP's 480x272 display. Save processing is
still completely offline.
