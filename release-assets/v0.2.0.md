## Download and install

Download **PUSE-PSP-v0.2.0.zip** from the Assets section below.

1. Extract the complete `PUSE-PSP` folder.
2. Copy it to `ms0:/PSP/GAME/PUSE-PSP/` on the PSP Memory Stick.
3. Confirm that `EBOOT.PBP` and the `data` folder are both inside that folder.
4. Exit Pokemon Unbound and your GBA emulator completely.
5. Start **PUSE-PSP** from the PSP Game menu and choose the 128 KiB `.sav` or `.srm` file.

Use **O** to confirm and **X** to cancel. Keep a separate manual backup while
this release is experimental. PUSE-PSP also creates a `.puse.bak` file before
replacing a save.

## Highlights

- Offline Party and PC editing directly on PSP
- Named Unbound species, item, nature, ability, and move catalogs
- Pokemon creation, release, deposit, withdrawal, and swapping
- Compatible/All Moves modes, current PP, PP Ups, and PP Max
- Bag, money, Battle Points, Pokedex, RTC Time Fixer reset, and save-health tools
- Validated temporary writes and automatic backup restoration on failure
