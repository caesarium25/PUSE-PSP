## Download and install

Download **PUSE-PSP-v0.5.2.zip** from the Assets section below.

1. Extract the complete `PUSE-PSP` folder.
2. Copy it to `ms0:/PSP/GAME/PUSE-PSP/` on the PSP Memory Stick.
3. Confirm that `EBOOT.PBP` and the `data` folder are both inside that folder.
4. Exit Pokemon Unbound and your GBA emulator completely.
5. Start **PUSE-PSP** from the PSP Game menu.

Keep a separate manual backup while this release is experimental. PUSE-PSP
also creates a `.puse.bak` file before replacing a save.

## v0.5.2 highlights

- Use `L/R` in PC storage to move directly between boxes
- Box navigation wraps between the first and last box
- PC storage remembers the last box and each box's highlighted slot
- Returning from a submenu restores the parent menu's previous row
- Cursor memory covers the main menu, Party, Bag, Pokemon editors, move editors,
  Money/BP, Pokedex, RTC recovery, and other shared menus
- Preserves the readable retained-frame UI, wrapped save paths, and Hoopa artwork
  introduced in v0.5.1

The editor remains completely offline and optimized for the PSP's 480x272 LCD.
