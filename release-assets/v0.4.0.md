## Download and install

Download **PUSE-PSP-v0.4.0.zip** from the Assets section below.

1. Extract the complete `PUSE-PSP` folder.
2. Copy it to `ms0:/PSP/GAME/PUSE-PSP/` on the PSP Memory Stick.
3. Confirm that `EBOOT.PBP` and the `data` folder are both inside that folder.
4. Exit Pokemon Unbound and your GBA emulator completely.
5. Start **PUSE-PSP** from the PSP Game menu and choose the 128 KiB `.sav` or `.srm` file.

Keep a separate manual backup while this release is experimental. PUSE-PSP
also creates a `.puse.bak` file before replacing a save.
